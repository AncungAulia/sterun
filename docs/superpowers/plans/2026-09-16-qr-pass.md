# QR pass implementation plan (STE-21 round 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runner opens `/pass/[tokenId]` on their phone and shows a QR and a six-character code that a volunteer can scan at a pickup desk with no signal.

**Architecture:** The page renders from what this device already stored at entry (IndexedDB), computes the code itself with Web Crypto, and only talks to the chain or the backend when there is a signal. A service worker scoped to `/pass` keeps the page loadable offline; every other route stays network-only.

**Tech Stack:** Next.js 16.3.3 App Router, React 19, TanStack Query, `qrcode` (SVG output), Web Crypto `crypto.subtle` for HMAC-SHA-256, idb-keyval, vitest + Testing Library.

Design: `docs/superpowers/specs/2026-09-16-qr-pass-design.md`. Screens: `docs/design/race-day/README.md` §2 and `exports/r1..r4`. Frozen rules: `docs/specs/HASH_AND_TOTP.md` §4-§5.

## Global Constraints

- **All UI text is English.** No em dash or en dash anywhere a user reads (`test/ui-rules.test.ts` enforces every spelling).
- **No hex, font name or raw px in a component.** Values come from `app/tokens.css`. Digits that must not jitter carry `class="numeric"`.
- **The code is a 6-character string, never a number.** Left-pad with `0`.
- **The QR payload is exactly** `{"t":<token>,"s":<step>,"c":"<code>"}` with no spaces and `c` as a string.
- **The secret never enters the QR, a log, or the chain.**
- Tests cover e2e + edge + positive + negative. Ask Ancung before running the full `fe` suite; never run `pnpm --filter fe build`.
- A file used by one feature lives in that feature; used by two, it moves up (`fe/guides/ARCHITECTURE.md` §4.2).
- Commits end with:

```ts
/**
 * The check-in code, computed on the runner's phone (docs/specs/HASH_AND_TOTP.md §4).
 *
 * Byte-exact by specification: the backend puts the same secret in the
 * scanner's roster, and both sides must produce the same six characters with no
 * network between them. Every rule here is the frozen document's, not ours.
 *
 * The code is a STRING, always six characters, left-padded with zero. Holding it
 * as a number drops that zero for about one runner in ten, and that failure only
 * shows up on race day (§4.4).
 */
const STEP_SECONDS = 30;

/** Which 30-second step a moment falls in. */
export function timeStepOf(unixSeconds: number): number {
  return Math.floor(unixSeconds / STEP_SECONDS);
}

/** How long this step has left, 30 down to 1, so a countdown never reads zero. */
export function secondsLeft(unixSeconds: number): number {
  return STEP_SECONDS - (Math.floor(unixSeconds) % STEP_SECONDS);
}

function bytesOf(hex: string): Uint8Array {
  if (!/^[0-9a-f]{64}$/.test(hex)) throw new Error("a secret is 64 lowercase hex characters");
  const bytes = new Uint8Array(32);
  for (let i = 0; i < 32; i++) bytes[i] = Number.parseInt(hex.slice(i * 2, i * 2 + 2), 16);
  return bytes;
}

/** The step as 8 big-endian bytes (T2). */
function counterOf(step: number): Uint8Array {
  const bytes = new Uint8Array(8);
  new DataView(bytes.buffer).setBigUint64(0, BigInt(step));
  return bytes;
}

export async function codeAt(secretHex: string, step: number): Promise<string> {
  const key = await crypto.subtle.importKey(
    "raw",
    bytesOf(secretHex),
    { name: "HMAC", hash: "SHA-256" },
    false,
    ["sign"],
  );
  const mac = new Uint8Array(await crypto.subtle.sign("HMAC", key, counterOf(step)));

  // RFC 4226 §5.3 dynamic truncation, over a 32-byte MAC (T4, T5).
  const offset = mac[31]! & 0x0f;
  const bin =
    ((mac[offset]! & 0x7f) << 24) | (mac[offset + 1]! << 16) | (mac[offset + 2]! << 8) | mac[offset + 3]!;

  return String(bin % 1_000_000).padStart(6, "0");
}

/**
 * Written as text rather than through JSON.stringify: the specification pins
 * three keys in one order with no spaces, and a template says that plainly.
 */
export function qrPayload(tokenId: number, step: number, code: string): string {
  return `{"t":${tokenId},"s":${step},"c":"${code}"}`;
}
```

```ts
"use client";

/**
 * Whether the phone thinks it has a signal.
 *
 * `navigator.onLine` is not a promise that requests will succeed, and at a
 * venue it often says yes over a WiFi with nothing behind it. That is fine
 * here: the banner it drives is reassurance ("your pass still works"), not a
 * decision. Nothing on this page waits for the network.
 */
import { useSyncExternalStore } from "react";

function subscribe(onChange: () => void): () => void {
  window.addEventListener("online", onChange);
  window.addEventListener("offline", onChange);
  return () => {
    window.removeEventListener("online", onChange);
    window.removeEventListener("offline", onChange);
  };
}

export function useOnline(): boolean {
  return useSyncExternalStore(
    subscribe,
    () => navigator.onLine,
    // The server has no network state, and a banner is never in the first paint.
    () => true,
  );
}
```

`fe/src/modules/pass/hooks/usePassCode.ts`:

```ts
"use client";

/**
 * The six characters and the QR payload for the step the phone is in.
 *
 * One interval at a second, rather than one timed to land on the boundary: a
 * phone that sleeps in a pocket wakes with its timers behind, and re-reading
 * the clock every second corrects that on the next tick. The code itself is
 * computed only when the step changes, because HMAC is asynchronous and the
 * QR must not be redrawn for a countdown.
 */
import { useEffect, useState } from "react";

import { codeAt, qrPayload, secondsLeft as leftInStep, timeStepOf } from "../lib/totp";

const nowSeconds = () => Math.floor(Date.now() / 1000);

export function usePassCode(tokenId: number, secretHex: string | null) {
  const [now, setNow] = useState(nowSeconds);
  const [code, setCode] = useState<string | null>(null);

  useEffect(() => {
    const id = setInterval(() => setNow(nowSeconds()), 1000);
    return () => clearInterval(id);
  }, []);

  const step = timeStepOf(now);

  useEffect(() => {
    if (!secretHex) {
      setCode(null);
      return;
    }
    let current = true;
    codeAt(secretHex, step)
      .then((next) => {
        if (current) setCode(next);
      })
      .catch(() => {
        // A secret this device cannot use is the same as none: the page falls
        // back to asking for it with the wallet rather than showing a wrong code.
        if (current) setCode(null);
      });
    return () => {
      current = false;
    };
  }, [secretHex, step]);

  return {
    code,
    payload: code === null ? null : qrPayload(tokenId, step, code),
    step,
    secondsLeft: leftInStep(now),
  };
}
```

```tsx
"use client";

/**
 * The payload as a QR, drawn as SVG on this phone.
 *
 * Never animated, in or out (the design's §6.3): a camera pointed at a
 * half-drawn code can read it, and reading it wrong is worse than reading
 * nothing. The new code replaces the old one in the same tick.
 *
 * `toString` is asynchronous, so the previous QR stays on screen until the next
 * one is ready rather than blinking through an empty box.
 */
import { useEffect, useState } from "react";

export function PassQr({ payload }: { payload: string }) {
  const [svg, setSvg] = useState("");

  useEffect(() => {
    let current = true;
    void import("qrcode").then(async ({ default: QRCode }) => {
      // M is the level the design's samples were generated at: enough redundancy
      // for a screen with fingerprints on it, without crowding the modules.
      const next = await QRCode.toString(payload, {
        type: "svg",
        errorCorrectionLevel: "M",
        margin: 1,
      });
      if (current) setSvg(next);
    });
    return () => {
      current = false;
    };
  }, [payload]);

  return (
    <div
      role="img"
      aria-label="Your check-in code as a QR"
      className="mx-auto aspect-square w-full max-w-67 [&>svg]:size-full"
      dangerouslySetInnerHTML={{ __html: svg }}
    />
  );
}
```

```tsx
"use client";

/**
 * `/pass/[tokenId]`: the runner's pass at a pickup desk (STE-21 round 2).
 *
 * ## It is drawn from this device first
 *
 * Everything the desk needs was written here at entry: the secret, the bib
 * name, the race and its distance. The chain is read when there is a signal,
 * to correct the bib and to learn whether the race pack has been collected,
 * and what it says is written back to the device so the next visit is right
 * with no signal at all. A failed read changes nothing on screen.
 *
 * ## The code is computed here, never fetched
 *
 * `usePassCode` runs the frozen TOTP definition against the stored secret. The
 * secret does not leave this phone, and the QR carries only its output for one
 * 30-second step.
 *
 * ## Without the secret there is no pass
 *
 * A phone that did not enter has nothing to compute from, so it offers to
 * fetch it with the wallet that owns the record (STE-52) rather than showing
 * an empty frame.
 */
import { useQuery } from "@tanstack/react-query";
import { useEffect } from "react";

import { ErrorNotice } from "@/components/feedback/ErrorNotice";
import { readClient } from "@/lib/chain/sterun";
import { readEntry, rememberPassFacts } from "@/lib/entry-store";

import { ClaimedPanel } from "./components/ClaimedPanel";
import { CodeRow } from "./components/CodeRow";
import { Countdown } from "./components/Countdown";
import { GetPassHere } from "./components/GetPassHere";
import { OfflineNotice, RolloverNotice } from "./components/PassNotices";
import { PassFacts } from "./components/PassFacts";
import { PassQr } from "./components/PassQr";
import { useOnline } from "./hooks/useOnline";
import { usePassCode } from "./hooks/usePassCode";

/** The last five seconds of a step, where the rollover note belongs. */
const ROLLOVER_SECONDS = 5;

export function PassPage({ tokenId }: { tokenId: number }) {
  const online = useOnline();

  const stored = useQuery({
    queryKey: ["stored-entry", tokenId],
    queryFn: async () => (await readEntry(tokenId)) ?? null,
    staleTime: 0,
  });

  const record = useQuery({
    queryKey: ["race-record", tokenId],
    queryFn: () => readClient.recordOf(tokenId),
    staleTime: 30_000,
    retry: false,
  });

  const entry = stored.data ?? null;
  const { code, payload, secondsLeft } = usePassCode(tokenId, entry?.totpSecret ?? null);

  // What the chain said, kept for the next visit, which may have no signal.
  useEffect(() => {
    if (!record.data || !entry) return;
    void rememberPassFacts(tokenId, {
      state: record.data.state,
      bibNo: record.data.bibNo,
      claimedAt: record.data.claimedAt?.toString(),
    }).catch(() => {});
  }, [record.data, entry, tokenId]);

  if (stored.isPending) {
    return (
      <div role="status" aria-label="Opening your pass" className="h-72 animate-pulse rounded-lg bg-n-100" />
    );
  }

  if (!entry) return <GetPassHere tokenId={tokenId} />;

  const state = record.data?.state ?? entry.state ?? "Entered";
  const claimed = state !== "Entered";
  const claimedAt = record.data?.claimedAt ?? (entry.claimedAt ? BigInt(entry.claimedAt) : null);
  const bibNo = record.data?.bibNo ?? entry.bibNo;

  return (
    <div className="mx-auto flex w-full max-w-md flex-col gap-6 px-5 py-6">
      {!online && !claimed ? <OfflineNotice /> : null}

      <PassFacts
        raceName={entry.raceName}
        distanceCode={entry.distanceCode}
        startsAt={BigInt(entry.startsAt)}
        city={entry.city}
        bibNo={bibNo}
        claimed={claimed}
      />

      {claimed ? (
        <ClaimedPanel eventId={entry.eventId} tokenId={tokenId} claimedAt={claimedAt} />
      ) : payload && code ? (
        <>
          <div className="flex flex-col gap-4 rounded-lg border border-n-200 bg-card p-4">
            <PassQr payload={payload} />
            <Countdown secondsLeft={secondsLeft} />
          </div>
          <CodeRow code={code} />
          {secondsLeft <= ROLLOVER_SECONDS ? (
            <RolloverNotice />
          ) : (
            <p className="text-center text-sm text-n-600">
              Works without signal. Keep the screen bright.
            </p>
          )}
        </>
      ) : (
        <ErrorNotice
          title="We could not make your code on this phone"
          detail="Open this pass again, or fetch it with the wallet that entered."
        />
      )}
    </div>
  );
}
```

```ts
/**
 * The secret, fetched for a phone that did not enter (STE-52).
 *
 * The second and last place a `totp_secret` leaves the vault; the first is the
 * scanner's roster. The backend checks `owner_of(token_id)` on chain before it
 * reads anything, so only the wallet that entered can ask, and a record is
 * non-transferable, which makes that owner the runner.
 */
import { apiFetch } from "@/lib/api/client";
import type { MessageSigner } from "@/lib/api/upload";

export async function fetchPass(
  tokenId: number,
  address: string,
  sign: MessageSigner,
): Promise<{ totpSecret: string; bibName: string | null }> {
  const challenge = await apiFetch<{ nonce: string; expires_at: string }>("/auth/challenge", {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({ address }),
  });

  const signature = await sign(challenge.nonce, { address });
```

```tsx
 * because a pass with a secret and no race name is not a pass.

import { useState } from "react";

import { Button } from "@/components/ui/button";

import { useWallet } from "@/hooks/useWallet";
import { ApiError } from "@/lib/api/client";
import { readClient } from "@/lib/chain/sterun";

import { getEventSummary } from "@/lib/event/events";

export function GetPassHere({ tokenId }: { tokenId: number }) {
  const address = useWallet((state) => state.address);
  const [busy, setBusy] = useState(false);
  const [problem, setProblem] = useState<string | null>(null);

  async function getIt() {
    if (!address) return;

    setProblem(null);
    try {
      const { signMessage } = await import("@/lib/wallet/kit");
      const [pass, record] = await Promise.all([

        readClient.recordOf(tokenId),

        salt: "",
        totpSecret: pass.totpSecret,
        txHash: "",

          {busy ? "Check your wallet" : "Get my pass"}
```

```tsx
"use client";

/**
 * Registers the pass's service worker, scoped to `/pass` and nothing else.
 *
 * The scope is the whole point. A worker over the origin would cache the
 * directory and the race pages, and a cached race page is a page that can show
 * a quota the chain no longer agrees with, which is the one claim this product
 * cannot afford to break (docs/WEB_APP_IA.md §1).
 */
import { useEffect } from "react";

export function OfflineReady() {
  useEffect(() => {
    if (!("serviceWorker" in navigator)) return;
    // Failure is silent on purpose: a pass that did not cache still works for
    // as long as it is open, which is the whole of a pickup desk visit.
    void navigator.serviceWorker.register("/pass-sw.js", { scope: "/pass" }).catch(() => {});
  }, []);

  return null;
}
```

`fe/public/pass-sw.js`:

```js
/*
  The pass's service worker. Scope: /pass only.

  What it does: keeps the last successful response for anything the pass needs
  (its own HTML, the Next build's JS and CSS, the fonts) and serves that copy
  when the network fails. A venue has no signal, and a reload there must not
  end at the browser's dinosaur.

  What it deliberately does not do: cache anything under /events, /org or /, so
  a stale race page can never be served as if it were the chain's answer.
*/
const CACHE = "sterun-pass-v1";

self.addEventListener("install", () => {
  // Nothing is precached: the build's asset names are not known here. The first
  // online visit fills the cache through fetch below, which is why the pass says
  // it needs signal once.
  self.skipWaiting();
});

self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches
      .keys()
      .then((keys) => Promise.all(keys.filter((key) => key !== CACHE).map((key) => caches.delete(key))))
      .then(() => self.clients.claim()),
  );
});

function cacheable(request) {
  if (request.method !== "GET") return false;
  const url = new URL(request.url);
  if (url.origin !== self.location.origin) return false;
  return url.pathname.startsWith("/pass") || url.pathname.startsWith("/_next/");
}

self.addEventListener("fetch", (event) => {
  if (!cacheable(event.request)) return;

  event.respondWith(
    fetch(event.request)
      .then((response) => {
        if (response.ok) {
          const copy = response.clone();
          void caches.open(CACHE).then((cache) => cache.put(event.request, copy));
        }
        return response;
      })
      .catch(async () => {
        const hit = await caches.match(event.request);
        if (hit) return hit;
        // A navigation to a pass this phone has not opened before: there is
        // nothing honest to show, so let the browser report the failure.
        return Response.error();
      }),
  );
});
```
